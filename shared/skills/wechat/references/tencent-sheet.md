# Tencent Sheet delivery

Load this reference only when the user requests a specific Tencent destination.
Use the currently installed Tencent document workflow and live tool schema for
that write. When working in chile-ops, its data-access instructions identify the
available channel. If a tool is absent from the current catalog, inspect the
existing mcporter connections before declaring it unavailable.

First prepare the mapping from each visually confirmed image to its product,
quote, source message, and target row. Read the current sheet headers and
identity columns. Resolve conflicts and retain the user's formulas and layout.
Write only the requested cells or image anchors. An image anchor can overwrite
cell text, so use the sheet's established image column.

Keep the full-size recovered files locally. Check the upload tool's scaling and
size limits before calling an embedded image a full-size copy. Read back the
written values, image anchors and adjacent text. A successful upload response
alone does not prove the intended row now contains the correct image. Inspect
an uncertain write before retrying.

Report local recovery and cloud delivery separately. Include the requested
sheet link and any unresolved image or quote attribution on the deliverable.
