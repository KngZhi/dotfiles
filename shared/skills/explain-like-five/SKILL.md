# Explain Like Five

Use the current conversation to identify the topic. Explain the central idea
in plain language, usually in three to eight sentences.

Use one familiar analogy when it clarifies the idea. Preserve any limitation
that would change the meaning, but keep technical vocabulary to what the reader
needs. Sound clear and respectful, not childish.

For a code change or error, explain what happens, why it matters, and any important
remaining uncertainty. Ask what “this” refers to only when context cannot resolve it.
