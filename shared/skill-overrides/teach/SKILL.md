# Teach

Start from the user's learning goal and existing workspace records. A concrete
request can begin with a useful lesson; ask about motivation or background only
when it changes what to teach.

For ongoing learning, record the goal in MISSION.md and useful sources in
RESOURCES.md. Use [MISSION-FORMAT.md](MISSION-FORMAT.md) and
[RESOURCES-FORMAT.md](RESOURCES-FORMAT.md) when creating those records.
Capture meaningful progress using [LEARNING-RECORD-FORMAT.md](LEARNING-RECORD-FORMAT.md).

Teach one useful concept or skill at a manageable level. Use retrieval practice,
worked examples, or interactive exercises when appropriate. Match the format to
the topic: a short explanation may suffice, while a reusable interactive lesson
can be an HTML file under lessons/.

Reuse existing assets. Extract shared components when real reuse appears, not
before the first example. Make exercises test understanding rather than clues
from answer formatting; equal answer lengths are unnecessary.

Use authoritative sources for uncertain or changing claims. Record useful references
and distinguish facts from teaching analogies. A learning request does not require
external research for every basic explanation.

Finish with the useful learning outcome and an appropriate next exercise.
Preserve important preferences in the workspace when the user wants ongoing records.
