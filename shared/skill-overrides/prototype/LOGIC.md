# Logic Prototype

Use a small runnable example or standalone HTML file that exposes the state and
lets the user exercise the transitions under discussion. Prefer the form that
best fits the question and available environment.

Include representative normal and difficult cases, with visible inputs and
outcomes. Use guided examples when they help explain ordering or dependencies.

production implementation. Report which behavior is demonstrated and which
external integrations or persistence guarantees remain untested.
