Use the grilling skill to explore the plan. Read relevant existing domain notes
and decisions when they help. Record agreed terms in the project's glossary and
important hard-to-reverse choices in its decision records, following local formats.
Create a document only when there is useful agreed content to preserve.

The conversation should resolve the plan's meaningful uncertainties. No separate
domain-modeling skill or project setup is required.
