# Compare Interface Shapes

For a consequential design choice, sketch materially different interfaces and
try representative callers against them. Include the current or simpler shape
when it is viable.

Compare required caller knowledge, ownership, error handling, and change locality.
Discard a candidate when real use exposes unnecessary coupling. Stop when the
evidence distinguishes the options.

Independent designs can reduce anchoring when authorized reviewers or subagents
are available. They are optional; a small decision does not require multiple
agents, a fixed number of candidates, or a formal scorecard.
