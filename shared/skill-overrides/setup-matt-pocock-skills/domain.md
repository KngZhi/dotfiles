# Domain Documents

Consult the relevant glossary or decision record when terminology, ownership,
or a consequential design choice needs context. Routine edits need not load a
repository map first.

Use the project's existing layout. A root CONTEXT.md and docs/adr/ are sufficient
for a single domain; if CONTEXT-MAP.md exists, follow only the relevant entries.
Missing documents are not a blocker and do not need to be created preemptively.

Preserve established domain terms. When an agreed definition or significant
hard-to-reverse decision needs recording, use the existing document format.
Flag a proposed change that contradicts an applicable decision and explain the
evidence for revisiting it.
